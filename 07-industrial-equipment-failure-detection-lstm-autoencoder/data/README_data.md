# Data Guide

## Included sample

`sample_equipment_sensor_data.csv` contains **420 rows from six synthetic equipment units**. It is a safe subset of the deterministic turbofan-style dataset generated by the original notebook.

| Column | Meaning |
|---|---|
| `unit_id` | Synthetic equipment identifier |
| `cycle` | Sequential operating cycle |
| `failure_label` | Evaluation label; 1 during the simulated pre-failure period |
| `sensor_1` … `sensor_8` | Simulated multivariate sensor measurements |

## Important data-safety position

The repository does not contain proprietary plant, customer, maintenance, or equipment-identification data. Do not commit confidential industrial data. For a real dataset, anonymize equipment IDs, remove operationally sensitive fields, document redistribution rights, and keep large/private files outside Git.

## Expected upload schema

The provided trained model expects the exact feature order below:

```text
unit_id, cycle, failure_label (optional for inference), sensor_1, sensor_2,
sensor_3, sensor_4, sensor_5, sensor_6, sensor_7, sensor_8
```

Each selected equipment ID must contain at least **20 chronologically ordered rows**. Uploaded data should come from a sensor process calibrated consistently with the training data; arbitrary column remapping is intentionally not allowed because it would produce misleading results.
